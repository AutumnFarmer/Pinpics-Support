照片如何被使用

Pinpics 用于浏览和整理你的照片，并把年度或出行经历做成可以编辑、保存和导出的图文回忆。经你通过系统授权，应用读取授权范围内的照片、视频及其拍摄日期、位置、收藏状态、尺寸、时长和资源标识，用于照片展示、年份与地点分组、统计、选取封面及生成回忆。

照片索引、封面筛选、作品编辑和回忆文字在设备上处理。封面筛选使用 Apple 的本机图像分析能力；回忆文字由本地规则和预置文案组成，当前版本没有接入生成式 AI 服务，也不会把你的照片或文字发送给大模型。应用没有账号、广告或第三方统计 SDK，不向开发者服务器自动上传图库、回忆或位置信息，也不进行跨应用广告跟踪。

什么时候会使用网络

地点识别、地图及 iCloud 照片读取会使用 Apple 提供的服务。

地点名称查询：批量整理按区域合并查询，发送区域内照片坐标的平均值；查看照片详情时，也可能发送该张照片的坐标以查询地址。平均值仍可能是精确位置；区域内只有一张照片时，它可能与该照片原有坐标相同。

地图：地图显示与浏览会向 Apple 请求相应区域的地图内容。

iCloud 照片：图片或视频未保存在本机时，展示、封面筛选、播放和导出可能通过系统照片服务下载所需资源，包括缩略图或原件。

Pinpics 不请求设备的实时定位权限；上述位置来自你已授权照片中的位置记录。Apple 服务按其自身规则处理请求，详见 Apple 隐私政策。

本机保存、备份与删除

应用在本机保存照片索引、地点查询结果、封面选择记录，以及你保存的回忆文字、布局和照片引用。保存一篇回忆通常保存的是照片引用，原照片仍由系统照片图库管理；授权变化或原照片删除后，作品中的图片可能无法显示。

系统设备备份由 iOS 和你的备份设置控制，保存的作品及编辑内容可能随设备备份保存。Pinpics 当前不提供自己的多设备云同步服务，系统备份也不等同于作品实时同步。

你可以在作品列表或作品菜单删除回忆。删除作品只移除该作品，不会删除系统图库中的照片。删除图库照片需要你主动发起，并按系统提示确认；如启用了 iCloud 照片，图库删除可能同步到使用同一图库的其他设备。卸载应用会移除其本机应用数据；系统备份及已经导出的副本需要在对应系统、应用或服务中管理。

应用会保存网格列数等本机偏好。导出和分享会产生临时文件：取消或明确失败后，应用清理本次文件；成功交接后的文件会保留供接收应用读取，并在创建超过 24 小时后的后续启动中清理。iOS 也可能按系统规则清理临时存储。

授权与选择

你可以只授权部分照片，也可以在系统设置中扩大、收紧或撤销照片访问范围。拒绝或撤销授权后，相应照片功能将无法使用；有限授权可能影响统计、地点分组和回忆选图的完整性。

收紧授权不会自动删除已保存的回忆文字、照片引用和地点缓存。如希望移除这些本机数据，可删除对应作品或卸载应用；如希望处理系统备份，应同时在 Apple 设置中管理相关备份。

导出与分享

只有你主动选择分享目标后，内容才会交给对应应用或服务。回忆长图和网页包含你选择的照片、文字、日期及地点；网页文件还包含用于排版的结构化内容和照片引用。回忆中使用的图片会重新编码，但可见内容本身仍可能透露个人信息。直接分享照片、视频或未编辑原件时，文件可能保留拍摄位置等原始元数据。

请在分享前检查成品和接收方。对方如何保存、使用或再次分享副本，受接收方的规则及你的操作影响；删除 Pinpics 中的作品不会删除已发送出去的文件。

联系支持时的信息

当你主动向支持邮箱发送邮件时，开发者会收到你的邮箱地址、邮件内容和你自行提供的附件。我们仅为回复咨询、排查问题、处理反馈或履行必要法律义务使用这些信息，不将其用于广告投放或出售。支持邮件由所使用的邮件服务商处理，适用其服务与隐私规则。

请只提供排查所需的信息，例如应用版本、设备型号和操作步骤；无需提供整个相册，也请勿发送密码、验证码或未经处理的私人照片。支持信息仅在处理问题、跟进反馈及依法必须留存的范围内保存；无需继续保留时删除。你可以通过支持邮箱请求查阅、更正或删除自己发送的支持信息。开发者无法远程查看或删除仅保存在你设备上的图库和作品。

支持网站访问

支持网站和本隐私政策网页由 GitHub Pages 托管。访问这些网页时，浏览器会向 GitHub 发送正常的网页请求；GitHub 会为安全目的记录访问者的 IP 地址，并可能处理请求时间、设备或浏览器信息等访问日志。本站页面没有加入广告、分析脚本、跟踪像素或表单。GitHub 对托管请求的处理详见 GitHub 隐私声明。

政策更新与联系

如果应用的数据用途或服务发生变化，我们会更新本政策；需要新的系统授权时，会提供相应说明与选择。关于本政策、数据处理或使用问题，请联系 zheju0609@gmail.com。
